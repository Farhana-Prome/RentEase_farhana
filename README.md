# RentEase

## Project Overview

RentEase is a web application designed to simplify the process of finding, managing, and renting properties.  

**Project URL**: [https://github.com/maha-shweta/RentEase](https://github.com/maha-shweta/RentEase)

---

## How to Edit This Project

You can work on RentEase in several ways:

### **1. Use Your Local IDE**
To work locally using VS Code or any preferred IDE:

```sh
# Step 1: Clone the repository
git clone https://github.com/maha-shweta/RentEase.git

# Step 2: Navigate into the project directory
cd RentEase

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
